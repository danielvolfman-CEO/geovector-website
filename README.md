# ГеоВектор — лазерное сканирование

Независимый статический прототип страницы, собранный с нуля по визуальному направлению действующего сайта.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска открыть `http://localhost:4173`.

## Структура

- `index.html` — семантическая разметка страницы;
- `styles.css` — визуальная система и адаптивность;
- `script.js` — мобильное меню, сдержанный scan-эффект и временная логика формы;
- `design/` — утверждаемые визуальные референсы первых разделов.

Текущие видео и часть изображений используются как временные внешние источники. Перед публикацией их нужно заменить локальными оптимизированными файлами.
